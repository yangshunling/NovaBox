署名配置

署名会出现在排版结果的封面与落款位置。保存后一直生效 —— 存在本机配置库 （~/.toolbox）里，关了程序重开还在，留空则不显示署名。

文章抓取

粘贴公众号文章链接，抓到的正文会自动转成 Markdown 填进下方编辑器。 浏览器受同源策略限制无法直连 mp.weixin.qq.com，请求会依次经 r.jina.ai / allorigins / corsproxy.io 等公共代理转发， 请勿填写私密或需要登录的链接。

公众号文章、普通网页都行

配置模型

填到 /v1 或 /chat/completions 都行，程序会自动补全接口路径
